# CREDO PRD

## One-liner
CREDO is the quiet companion for Sunday Mass.

## Promise
Prepare for Mass. Attend with understanding. Receive what was given. Live it this week.

## Problem
Many Catholics attend Mass without understanding the readings, gestures, and spiritual meaning. Catholic apps often provide either prayer content, utility tools, or large libraries. Few guide ordinary Catholics through a simple weekly Mass rhythm.

## MVP Goal
Prove that users will open CREDO weekly to prepare for Sunday Mass and return after Mass to reflect and live one truth.

## Target users
- Practicing Catholics who want to understand Mass more deeply
- Returning Catholics
- TLM-curious Catholics, later
- Seekers exploring Catholicism, lightly supported
- Parents/catechists later, not v1 core

## v1 Scope
- Welcome / onboarding
- Sunday Home
- Prepare flow
- Prayer Mode
- Receive reflection
- Live This Week
- Way reflections
- Mass section deep dive

## Success metrics
- % onboarding completed
- % users completing Prepare
- % users opening Prayer Mode
- % users saving Reflection
- % returning next Sunday
- qualitative feedback: “I would use this before Mass”

## Non-goals for v1
- Full catechism library
- AI chat
- Confession companion
- Family mode
- Catechist mode
- Parish/school SaaS
- Payment/subscription
- Social features
