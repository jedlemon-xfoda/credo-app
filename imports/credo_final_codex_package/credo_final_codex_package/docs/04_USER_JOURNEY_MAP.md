# User Journey Map

## Acquisition
User sees: “A quiet companion for Sunday Mass.”

## First 60 seconds
1. Welcome
2. One question: “What brings you here?”
3. Land on Sunday Home
4. CTA: Prepare

## First Sunday
1. Prepare readings
2. Learn what to notice
3. Enter Prayer Mode during Mass
4. Save for later if needed
5. Reflect after Mass
6. Live one truth during the week

## First month
User prepares for 3–4 Sundays and accumulates reflections in Way.

## Retention loop
Saturday/Sunday: Prepare
During Mass: Attend / Prayer Mode
After Mass: Receive
Weekday: Live
Repeat next Sunday
