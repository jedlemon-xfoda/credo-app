# Use Cases

## UC1: Practicing Catholic prepares for Sunday
As a practicing Catholic, I want to understand the readings and what to notice at Mass so I can attend more fruitfully.

## UC2: User uses Prayer Mode
As a user at Mass, I want a quiet, low-distraction companion so I can understand the current moment without being pulled out of prayer.

## UC3: User reflects after Mass
As a user after Mass, I want to briefly record what drew my attention so I can remember and live it.

## UC4: Returning Catholic starts gently
As a returning Catholic, I want a gentle entry into Sunday Mass without feeling judged or overwhelmed.

## UC5: Seeker explores lightly
As someone exploring Catholicism, I want a clear Sunday-centered entry point rather than a giant library.
